📄 Project Title — Responsive Web Page (From Scratch)
📌 Overview

This project is a fully responsive and accessible web page built from scratch using only HTML and CSS — without any external libraries or frameworks.
The goal of the project is to recreate a provided designer file as accurately as possible while applying key concepts such as:

Semantic HTML

CSS layout (Flexbox / Grid)

Responsive design

Accessibility best practices

Interactive states (hover, active, focus)
